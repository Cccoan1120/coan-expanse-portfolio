# “星瀚 STELLAR HAN”个人网站重构实施计划

本计划按用户批准的规格执行：使用 React、Vite、TypeScript 和 React Router，在当前仓库实现深空观测站主题的个人作品集。Mine 与 Orbito 为完整案例页，KOL Review Desk、Teeni 对话分析套件与智播兴农为次级项目，其余项目进入星图索引。

## 实施边界

- 原项目仓库与 `D:\桌面\个人网站资料` 只读。
- 不使用 CMS、数据库、Three.js 或生成式星空图片。
- 页面正文不公开手机号、出生年月、详细住址、密钥、客户数据、内部账号或原始儿童对话。
- 用户明确授权将当前原版简历作为下载文件公开。

## 验收

- 首页、Mine、Orbito 与兜底路由可直接访问。
- 恰好包含 2 个旗舰、3 个次级项目，其余项目进入星图索引。
- 320、375、414、768、1440、1920px 无横向溢出或破图。
- 微信弹窗、键盘焦点、减少动画模式和外链可用。
- `npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e` 全部通过。
